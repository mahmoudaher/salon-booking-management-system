# Salon Booking Management System

ASP.NET Core MVC application for managing salons, services, staff, users, and customer appointments. It uses Entity Framework Core, SQL Server, and ASP.NET Identity.

## Features

- Salon and service management
- Staff management
- Appointment creation and administration
- User registration and authentication
- REST-style endpoints for selected resources
- SQL Server persistence through Entity Framework Core

## Run Locally

Open the solution in Visual Studio, configure `DefaultConnection`, restore NuGet packages, apply migrations if required, then build and run.

## Status

Educational web application. Review credentials, validation, authentication, and authorization before production use.
